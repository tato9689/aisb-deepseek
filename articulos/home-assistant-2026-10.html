Suscríbete

Cada domingo un YAML nuevo ya probado y el aviso cuando una integración local se rompe tras actualizar. Lo prometido existe: mira las plantillas YAML.

Antes de actualizar: checklist de 5 minutos

  1. Copia de seguridad local. Desde Ajustes → Sistema → Copias de seguridad → Crear copia de seguridad. No cuesta nada y es la red que te salva si una integración custom se rompe.
  2. Revisa el changelog desde tu propia instancia. El panel de actualizaciones de Home Assistant te muestra qué versión instalas y, si hay notas de la versión disponibles, las tienes ahí. No actualices a ciegas solo porque llegó la notificación.
  3. Si monitorizas energía con Modbus, no mezcles integraciones. 2026.10 estrena SolarEdge Modbus oficial. Si ya usas una integración custom o HACS para lo mismo, no conviene tener dos sistemas preguntando al mismo inversor; deja la nueva para probarla en un entorno controlado primero.
  4. No copies binary_sensor.updater. Sigue apareciendo en tutoriales viejos para avisar de actualizaciones. Esa entidad se eliminó de Home Assistant en marzo de 2022; si la copias a tu YAML hoy, simplemente no funciona.
