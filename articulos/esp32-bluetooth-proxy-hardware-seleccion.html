ESP32 para Bluetooth Proxy: qué placa elegir y qué mirar antes

Publicado el 11 de noviembre de 2026 · Última revisión: 11/11/2026

Si solo quieres una respuesta: casi cualquier ESP32 con WiFi 2,4 GHz y BLE sirve. El fallo casi nunca es la placa; es el cable de carga, la antena o la alimentación. Aquí tienes los criterios para no comprar de más ni de menos.

La decisión en una frase

Un Bluetooth Proxy es un ESP32 con ESPHome que captura anuncios BLE (sensores de temperatura, cerraduras, balizas) y se los reenvía a Home Assistant. La placa no ejecuta la integración Bluetooth de HA: solo escucha y traduce. Por eso el rendimiento depende de la radio BLE, la estabilidad del WiFi y la alimentación, no de la potencia bruta de CPU.

Qué cambia entre las familias de ESP32 para un proxy Bluetooth
Familia Conectividad habitual Ventaja para proxy A tener en cuenta
ESP32 clásico (WROOM-32) WiFi 2,4 GHz + BLE La más documentada y compatible con ESPHome Suele consumir algo más; casi siempre funciona sin sorpresas
ESP32-C3 WiFi 2,4 GHz + BLE Barata, con BLE 5 y menos consumo Menos pines GPIO; revisa el conector USB de la placa concreta
ESP32-S3 WiFi 2,4 GHz + BLE 5 Más RAM y mejor radio si convives con muchos dispositivos Es más cara; rara vez necesitas la potencia extra para un proxy

Las versiones de silicio y la disponibilidad cambian rápido; trata esta tabla como criterio, no como ranking. El modelo exacto que compres importa menos que el conector USB y la antena.

Los fallos que no se arreglan cambiando de placa

La mayoría de los problemas de un proxy BLE no vienen del ESP32: vienen de un cable USB sin datos, una antena pegada al router o una fuente inestable. Lo tengo documentado en la guía de fallos comunes. Aquí dejo el mínimo para probar tu placa:

esphome:
  name: proxy-ble
  friendly_name: Proxy BLE

esp32:
  board: esp32dev
  framework:
    type: arduino

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

esp32_ble_tracker:
  scan_parameters:
    active: true

bluetooth_proxy:
  active: true

logger:
api:
ota:

Cambia board por el de tu placa si es un C3 o S3. El resto es igual.

Qué no necesitas

  • No necesitas un ESP32 con pantalla. El proxy no tiene interfaz; se gestiona desde Home Assistant.
  • No necesitas PoE. Un micro-USB o USB-C estable y una fuente de 1 A sobran.
  • No necesitas antena externa salvo que el sensor BLE esté en otra planta o tras un muro grueso.
  • No necesitas un ESP32 por cada sensor. Uno solo suele cubrir una habitación y los pasillos cercanos.

Si dudas entre dos placas, compra la que tenga el conector USB más cómodo para dejarla enchufada. Es el factor que más afecta a un cacharro que tienes 24/7 en un armario.
