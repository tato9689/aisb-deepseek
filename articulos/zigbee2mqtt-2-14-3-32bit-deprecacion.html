Zigbee2MQTT 2.14.3: se termina el soporte para 32 bits

Publicado 1 de noviembre de 2026 · Versión 2.14.3 · Fuente: release notes e issue #33552 de Koenkk

El 1 de noviembre de 2026 salió Zigbee2MQTT 2.14.3. La novedad no es una mejora: es la confirmación de que las plataformas de 32 bits están deprecadas y se quedarán sin soporte cuando Node.js 22 llegue al final de su vida útil, en abril de 2027.

Qué dice exactamente el aviso

La nota del release es corta y no deja margen:

Running Zigbee2MQTT on 32-bit platforms is deprecated, and support ends when Node.js 22 reaches end-of-life (April 2027). At that point the minimum supported Node.js version becomes v24, and Node.js v24 no longer ships official builds for any 32-bit platform.

En la práctica: si tu instalación corre sobre un sistema operativo de 32 bits, las actualizaciones de Zigbee2MQTT se detendrán en abril de 2027, no porque lo decida el proyecto, sino porque Node.js 24 ya no compila binarios oficiales para esas arquitecturas.

A quién afecta, en concreto

Método de instalación y efecto de la deprecación de 32 bits
Instalación Arquitecturas 32 bits Qué pasa a partir de abril de 2027
Docker oficial linux/386, linux/arm/v6, linux/arm/v7 Las imágenes dejan de actualizarse
Sobre el sistema (bare-metal) Cualquier SO de 32 bits No podrás ejecutar una versión de Node soportada
Hardware típico Raspberry Pi 1/Zero, instalaciones antiguas de Raspberry Pi OS de 32 bits Habrá que pasar a sistema operativo o hardware de 64 bits

Cómo comprobar si estás en 32 bits

En una Raspberry Pi o cualquier Linux, ejecuta:

uname -m
dpkg --print-architecture

Si la respuesta es armv7l, armv6l o i686, estás en 32 bits. En una instalación Docker puedes verlo con:

docker system info | grep Architecture

Plan de migración antes de abril de 2027

  1. Comprueba la arquitectura con los comandos de arriba. Si ya es aarch64 o amd64, no tienes que hacer nada.
  2. Si es 32 bits y el hardware lo permite, reinstala con un sistema operativo de 64 bits. En una Raspberry Pi 2 v1.2 o superior puedes usar Raspberry Pi OS de 64 bits.
  3. Si el hardware no soporta 64 bits (Raspberry Pi 1, Zero v1), planifica el cambio de equipo antes de abril de 2027.
  4. Haz copia de seguridad de la configuración de Zigbee2MQTT (configuration.yaml) y de los paneles de Home Assistant asociados antes de tocar nada.

Lo que no cambia hoy

Hasta abril de 2027 las imágenes y builds de 32 bits siguen funcionando. Este aviso no rompe nada inmediatamente: es el aviso formal para que no te pille el final del soporte de Node 22.

Fuentes: release 2.14.3 en GitHub y issue #33552.
