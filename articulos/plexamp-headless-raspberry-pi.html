Plexamp headless en Raspberry Pi: un reproductor de red sin pantalla, con systemd y control desde el móvil

Última revisión: 01/09

Plexamp headless es la build de Plexamp pensada para correr en una Raspberry Pi sin monitor: la Pi se conecta a tu equipo de audio, y el control va desde el móvil, la tablet o el ordenador con otra instancia de Plexamp. Es una pieza clásica de audio en red local: la biblioteca vive en tu servidor Plex, la Pi hace de reproductor, y todo circula por tu red sin depender de servicios externos salvo el arranque inicial con el claim token.

Qué necesitas

Elemento Requisito
Raspberry Pi Pi 3, 3B+, 4 o 5. La build headless corre sobre Linux ARM; en Pi 4 y 5 usa la de 64 bits si tu sistema operativo es arm64.
Servidor Plex Necesitas un Plex Media Server ya montado en tu red. Plexamp reproduce tu biblioteca; no funciona sin ese servidor.
Salida de audio jack de la Pi, USB DAC o HAT de audio. Plexamp usa ALSA; cualquier tarjeta reconocida por el sistema vale.
Control Plexamp en el móvil o escritorio, en la misma red o por tu Plex account.

Instalación sin escritorio

El patrón que confirma la documentación de Plex y las guías actualizadas de 2026 es el siguiente: una Pi con Raspberry Pi OS Lite, la build headless descomprimida en /opt/plexamp, un fichero de credenciales con tu claim token, y un servicio systemd que lo arranque solo.

1. Prepara la Pi

Instala Raspberry Pi OS Lite (sin escritorio), conéctala por SSH y actualiza:

sudo apt update && sudo apt upgrade -y
uname -m
# en Pi 4/5 debería responder aarch64, en Pi 3 armv7l

El resultado de uname -m te dice qué build de Plexamp tienes que bajar. Si no aparece aarch64 ni armv7l, para: algo raro hay en tu sistema.

2. Descarga Plexamp headless

Plex publica la build para Raspberry Pi en su propia web (plex.tv/plexamp). El nombre exacto del paquete y la URL cambian entre versiones: a fecha de 01/09 no lo he podido fijar porque Plex rota el enlace de descarga; lo que se mantiene estable es el contenido del paquete: un directorio con plexamp.js y un Node embebido. Descomprime ese paquete en /opt/plexamp con el usuario que vaya a ejecutarlo. Fuentes externas para contrastar: el gist de instalación headless de tgp-2 y el instalador bash de odinb (ambos públicos en GitHub).

3. Claim token y primer arranque

Antes de que Plexamp sepa qué servidor usar, la build headless pide autorización. Entra en https://www.plex.tv/claim/ con tu cuenta, copia el token de 4 letras y pégalo cuando el servicio lo pida en el primer arranque. Es el mismo mecanismo que usa Plex Media Server para darse de alta en tu cuenta.

El primer arranque lo haces a mano para ver los mensajes:

cd /opt/plexamp
node plexamp.js

Con suerte verás la URL de la interfaz web local (suele ir por el puerto 3000) y te pedirá el claim token. Si el claim no se valida, repite la operación: el token caduca a los minutos de generarlo.

4. Arranque automático con systemd

Un reproductor de red tiene que estar vivo cuando tú quieras música, no solo cuando te acuerdas de encenderlo. Crea un servicio systemd:

sudo nano /etc/systemd/system/plexamp.service
[Unit]
Description=Plexamp headless endpoint
After=network-online.target
Wants=network-online.target

[Service]
User=plexamp
WorkingDirectory=/opt/plexamp
ExecStart=/usr/bin/node plexamp.js
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target

Ajusta el usuario (User=) al que tenga permisos sobre /opt/plexamp, y la ruta de node si usas el Node embebido del paquete en vez del del sistema. Actívalo:

sudo systemctl daemon-reload
sudo systemctl enable --now plexamp
sudo systemctl status plexamp

Si no suena: los fallos que vas a encontrar

  • El servicio corre pero no hay audio. Plexamp manda por defecto a la tarjeta ALSA que el sistema tiene como predeterminada. Lista tus tarjetas con aplay -l y prueba el altavoz con speaker-test -c 2. Si tu DAC aparece como card 1, la solución no es pelear con Plexamp sino dejar esa tarjeta como predeterminada en tu asound.conf.
  • No arranca y no sabes por qué. journalctl -u plexamp -b te enseña el error real. El fallo más común es que el usuario del servicio no tiene permisos de escritura en /opt/plexamp para guardar su configuración.
  • El móvil no ve el reproductor. Comprueba que el móvil y la Pi están en la misma VLAN. Si separas redes de invitados, el descubrimiento de Plexamp no lo cruza solo.
  • Actualizar la build. Descarga el paquete nuevo, reemplaza /opt/plexamp conservando el fichero de credenciales y reinicia el servicio. Sin tocar credenciales, la reconfiguración no hace falta.

Por qué esto es audio en red local

El flujo entero — biblioteca, servidor, reproductor y control — vive en tu red. Lo único que sale de ella es la autenticación contra tu cuenta Plex, igual que cuando abres la app en el móvil. Si mañana te quedas sin fibra, la música entre servidor y Pi sigue funcionando en casa. Ese es exactamente el tipo de montaje que este sitio documenta: el proceso completo, con los fallos, para que lo copies.
