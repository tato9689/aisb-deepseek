Plexamp Headless en Raspberry Pi: systemd y arreglo del sign-in tras resetear contraseña

Última revisión: 06/10/2026

Foto de Tanha Tamanna Syed en Pexels

Plexamp Headless convierte una Raspberry Pi sin pantalla en un reproductor de tu biblioteca Plex. Lo instalas, lo dejas enchufado a un amplificador o a unos altavoces y lo manejas desde el móvil con la app de Plexamp. El punto débil es doble: el servicio de arranque falla cuando Node no está donde systemd espera, y en cuanto Plex te obliga a cambiar la contraseña, el headless pierde la sesión y desaparece como reproductor. Aquí está la instalación, el unit de systemd y los dos arreglos.

Lo que sigue sale de leer el instalador de odinb/bash-plexamp-installer, el gist de configuración de un usuario, la entrada de How To Hi-Fi (noviembre 2024) y la guía de Pi My Life Up (mayo 2026).

Qué vas a conseguir

  • Un reproductor headless: cualquier altavoz pasa a ser endpoint de Plex sin pantalla conectada, como explica Pi My Life Up.
  • Interfaz web de control en el puerto 32500 del Pi, por si no quieres depender solo del móvil.
  • Control remoto desde cualquier cliente Plexamp, seleccionando el reproductor headless con el icono Cast.
  • Un servicio systemd que arranca Plexamp al reiniciar, con el fallo de Node ya resuelto.

Instalación

El instalador que más guías enlazan es bash-plexamp-installer, pensado para Raspberry Pi con ARM64 y para gestionar Node con nvm. Clónalo y ejecuta su instalación:

git clone https://github.com/odinb/bash-plexamp-installer
cd bash-plexamp-installer
bash install.sh

No repito aquí cada pregunta del script porque cambian entre versiones. Sigue el README del repo, que está pensado para dejar el servicio funcionando al final.

Si vienes de una instalación antigua y el instalador nota Node obsoleto, lo sube con nvm y fija la versión en .nvmrc. El gist recoge estos dos pasos seguidos de un reinicio:

nvm install 24
echo "v24" > .nvmrc
reboot

El servicio systemd y el fallo de Node «no encontrado»

El instalador registra plexamp.service como unidad de usuario. Se gestiona así:

systemctl --user enable plexamp.service
systemctl --user start plexamp.service

El unit que deja queda parecido a esto, con las rutas dependiendo de dónde tengas cada cosa:

[Unit]
Description=Plexamp Headless
After=network-online.target

[Service]
ExecStart=/ruta/a/node /ruta/a/plexamp/js/index.js
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target

El fallo real más repetido lo documenta How To Hi-Fi: el unit sale con /usr/bin/node en ExecStart cuando Node lo instaló nvm en otra ruta. El servicio muere al arrancar y la web del puerto 32500 no responde. La solución que publicó el autor fue cambiar ExecStart para usar la versión explícita de nvm en lugar de la ruta genérica. Compruébalo tú con:

which node

Y pon esa ruta delante de /ruta/a/plexamp/js/index.js. Si cambias el unit, recárgalo:

systemctl --user daemon-reload
systemctl --user restart plexamp.service

Reset de contraseña: por qué se rompe y cómo arreglarlo

Plex avisa a veces de que debes cambiar la contraseña y cierra sesión en todos los dispositivos. El headless no es una excepción, y como no tiene pantalla, no se puede reautenticar desde él. El hilo del foro de Plex de septiembre de 2025 lo llama directamente "non-functional". La secuencia que lo devuelve a la vida, según el gist y ese hilo:

  1. Abre http://IP_DEL_PI:32500 (o pi.local:32500 en red local).
  2. Ve a Settings > Account. Pulsa sign out y vuelve a sign in.
  3. En la app de Plexamp del cliente, pulsa el icono Cast y re-selecciona el reproductor headless.
  4. Repasa los ajustes de reproducción: tras el sign-in algunos vuelven a valores por defecto, y el gist lo avisa explícitamente.

Un foro de 2022 documenta un arranque manual alternativo, sin pasar por systemd, para salir del paso:

cd plexamp/
node js/index.js

Control desde el móvil u otro equipo

Una vez autenticado, el reproductor headless sale en la app de Plexamp dentro del icono Cast. Lo eliges igual que un altavoz, y él estrena la música sobre los altavoces del Pi. Si además usas Music Assistant con Plex Connect, puedes cruzar ese altavoz con fuentes de otros servicios, pero ese es otro cableado.
